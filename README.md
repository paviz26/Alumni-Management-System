# Alumni Management System

A full-stack DBMS project for managing alumni profiles, institutional communication,
events, networking, mentorship, career opportunities, and donations.

## Team Responsibilities
- Jiya — Frontend
- Ankur — Backend
- Pavithra — PostgreSQL Database Design

## Technology Stack
- Frontend: React + Vite
- Backend: Node.js + Express.js
- Database: PostgreSQL
- API: REST
- Version Control: Git/GitHub

## Main Features
1. User registration and login
2. Alumni profile management
3. Alumni directory with search/filter
4. Department and batch management
5. Event creation and registration
6. Job and internship opportunities
7. Job applications
8. Alumni mentorship
9. Announcements
10. Donations
11. Admin dashboard
12. Alumni engagement statistics

## Setup
1. Create a PostgreSQL database named `alumni_management`.
2. Run `database/01_schema.sql`.
3. Run `database/02_sample_data.sql`.
4. Configure `backend/.env` using `backend/.env.example`.
5. Install backend dependencies with `cd backend && npm install`.
6. Start the backend server with `cd backend && npm run dev`.
7. Install frontend dependencies with `cd frontend && npm install`.
8. Start the frontend development server with `cd frontend && npm run dev`.
9. Open `http://localhost:3000` in your browser.

See `docs/setup.md` for detailed instructions.
