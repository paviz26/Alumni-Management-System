# Feature Specification

### Alumni
Registration, login, profile editing, directory, search and filtering.

### Events
Administrators can create events. Alumni can view and register for events.

### Careers
Alumni can publish jobs/internships and other alumni can apply.

### Mentorship
Alumni can request, accept, reject and complete mentorship relationships.

### Communication
Administrators can publish announcements.

### Donations
Alumni can record contributions and administrators can view donation statistics.

### Administration
Dashboard with alumni count, events, registrations, jobs, mentorship,
and donation statistics.
