# REST API

## Authentication
- POST `/api/auth/register`
- POST `/api/auth/login`

## Alumni
- GET `/api/alumni`
- GET `/api/alumni/:id`
- PUT `/api/alumni/:id`

## Events
- GET `/api/events`
- POST `/api/events`
- POST `/api/events/:id/register`

## Jobs
- GET `/api/jobs`
- POST `/api/jobs`

## Mentorship
- GET `/api/mentorship`
- POST `/api/mentorship`
- PUT `/api/mentorship/:id`

## Announcements
- GET `/api/announcements`
- POST `/api/announcements`
